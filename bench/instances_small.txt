# result directories had gone.  This one should not have gone with them: it
# is the set the kWeight* constants were measured on, and without it the
# calibration procedure in mode_dispatch.cpp has no defined input — a
# re-measurement on some other set is not comparable to the recorded
# numbers, and nobody can tell afterwards which set produced what.

# (Provenance, not a measured effect: on the one comparison available here

# this set alone.  Use the recorded set because it is the recorded set, not
# because a different one is known to shift the answer.)
