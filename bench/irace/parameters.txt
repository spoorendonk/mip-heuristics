# irace parameter space for issue #107: the joint search over heuristic mix,
# effort and patience.  Read by `bench/irace/scenario.txt`; every `switch` here
# is a contract with `bench/run_target.py`'s CLI, which is the single
# definition of what a configuration means.
#
# Format (irace >= 3.0): name, switch, type, domain, [| condition].
# Types used here: `c` categorical, `r,log` log-sampled real.
#
# The space is eight-dimensional: four efforts and four patiences.  The
# categoricals below are NOT extra dimensions — they are sampling machinery.
# #107's reduction is that the fifteen non-empty heuristic subsets plus `off`
# are exactly the zero-patterns of the four efforts, and a real sampled from a
# continuous domain essentially never lands on exactly 0, so "off" would be
# unreachable without a discrete switch.  `--<h>-enabled 0` is shorthand for
# that heuristic's effort being 0; `run_target.py` collapses it into the effort
# vector before anything else sees it, so the recorded configuration is always
# the eight numbers.  `--<h>-gated 0` is the same trick for patience 0, which
# means *no staleness gate at all* rather than "give up immediately" — a
# distinct configuration that log sampling likewise cannot reach.
#
# **The unit** of all eight is a multiple of `nnz << 10`, vanilla HiGHS's own
# hardcoded single-thread FeasibilityJump limit (#116), so `effort = 1.0` is
# exactly one vanilla FJ budget and a patience is directly comparable with the
# effort beside it.  The units are NOT comparable *across* heuristics: FJ
# counts step units, FPR and LocalMIP coefficient accesses, Scylla PDLP
# iterations x nnz.  That is why the domains below are per-heuristic.
#
# ── Where these domains come from ───────────────────────────────────────────
#
# The #113 calibration probe, re-run 2026-09-05/06 and shipped as the defaults
# in b212155.  Full derivation in `bench/ablation_effort/README.md`.  Each
# heuristic's *yield knee* — the p50 budget at which a dispatch made its last
# incumbent improvement — plus the censored upper bracket that carries the
# still-improving and barren dispatches:
#
#   heur        knee    censored hi
#   fj          0.5665      6.6125
#   fpr        12.2559     93.7124
#   local_mip  13.9607     50.8226
#   scylla      3.0680     17.8144
#
# Effort domain: `[knee/8, max(8*knee, 1.5*censored_hi)]`, with FJ's bottom
# raised to `0.08` — its charged effort moves in steps of
# `CALLBACK_EFFORT = 500000`, so its option is a no-op whenever
# `nnz * value < 488`, and `0.08` is the documented floor that clears it.  Three octaves
# below the measured centre, and above it whichever is larger of three octaves
# or half again beyond the censored bracket — so FPR's domain reaches 141
# where a single shared `(0.08, 80)` would have stopped below its own bracket.
# The previous shared domain predated the re-run and was chosen before any of
# these numbers existed.
#
# All bounds are written to at most **four decimal places**, because that is
# `irace::readParameters`' default `digits` and irace 4.x offers no scenario
# option to raise it — `digits` was a scenario variable in 3.x and is now
# rejected as unknown, which stops the run at startup.  FJ's patience floor is
# `0.0022` rather than the exact `knee/256 = 0.002213`; the rounding is 0.6%
# on a log-sampled bound whose purpose is to be far below the clamp.
#
# Patience domain: `[knee/256, effort_hi/4]`.  The top is the **clamp**:
# `patience_threshold` caps a patience at a quarter of that heuristic's own
# budget, so the top of the domain has to reach `effort_hi / 4` or a
# configuration that samples a large effort could not express the loosest
# gate at all.  #113 measured the raw p95 wait *above* the clamp on three of
# the four (fj 2.46, fpr 5649.87, local_mip 4.93, scylla 18.96 against the
# shipped ceilings 0.1416 / 3.064 / 3.490 / 0.767), so the clamp binds on
# every shipped default and the loose end is where the measurement points.
#
# The domain is therefore *over*-represented rather than degenerate: for a
# configuration whose effort is below the top of its domain, every patience
# above `effort/4` clamps to `effort/4` and so maps onto one real
# configuration — the loosest gate — instead of being inert.  That costs
# sampling resolution at the loose end, not correctness.  Reaching the clamp
# exactly at every effort would mean searching a *ratio*, which
# `run_target.py`'s CLI does not express and which `--<h>-gated` does not
# substitute for: gated 0 is *no gate*, while patience at the clamp is a gate
# that fires after a quarter of the budget without an improvement.  The two
# are different configurations and both are reachable here.
###############################################################################

# --- inclusion: the zero-pattern of the four efforts -------------------------
fj                  "--fj-enabled "         c     (0, 1)
fpr                 "--fpr-enabled "        c     (0, 1)
local_mip           "--local-mip-enabled "  c     (0, 1)
scylla              "--scylla-enabled "     c     (0, 1)

# --- effort: per-heuristic, centred on the #113 knee --------------------------
fj_effort           "--fj-effort "          r,log (0.08, 9.92)   | fj == "1"
fpr_effort          "--fpr-effort "         r,log (1.53, 141.0)    | fpr == "1"
local_mip_effort    "--local-mip-effort "   r,log (1.75, 112.0)    | local_mip == "1"
scylla_effort       "--scylla-effort "      r,log (0.384, 26.7)    | scylla == "1"

# --- whether the staleness gate is armed at all ------------------------------
# 0 selects patience 0, i.e. no gate; the heuristic then runs to its budget or
# the clock.  #113 found the measured wait above the clamp on three of four, so
# "no gate" is a serious candidate rather than a corner case.
fj_gated            "--fj-gated "           c     (0, 1)           | fj == "1"
fpr_gated           "--fpr-gated "          c     (0, 1)           | fpr == "1"
local_mip_gated     "--local-mip-gated "    c     (0, 1)           | local_mip == "1"
scylla_gated        "--scylla-gated "       c     (0, 1)           | scylla == "1"

# --- patience: below the clamp, which is a quarter of that heuristic's effort -
fj_patience         "--fj-patience "        r,log (0.0022, 2.48) | fj_gated == "1"
fpr_patience        "--fpr-patience "       r,log (0.0479, 35.3)   | fpr_gated == "1"
local_mip_patience  "--local-mip-patience " r,log (0.0545, 28.0)   | local_mip_gated == "1"
scylla_patience     "--scylla-patience "    r,log (0.012, 6.68)   | scylla_gated == "1"
