###############################################################################
# irace parameter space for issue #107: the joint search over heuristic mix,
# effort and patience.  Read by `bench/irace/scenario.txt`; every `switch` here
# is a contract with `bench/run_target.py`'s CLI, which is the single
# definition of what a configuration means.
#
# Format (irace >= 3.0): name, switch, type, domain, [| condition].
# Types used here: `c` categorical, `r,log` log-sampled real.
#
# The space is eight-dimensional: four efforts and four patiences.  The four
# `<h>` categoricals below are NOT a ninth through twelfth dimension — they are
# sampling machinery.  #107's reduction is that the fifteen non-empty heuristic
# subsets plus `off` are exactly the zero-patterns of the four efforts, and a
# real sampled from a continuous domain essentially never lands on exactly 0,
# so "off" would be unreachable without a discrete switch.  `--<h>-enabled 0`
# is shorthand for that heuristic's effort being 0; `run_target.py` collapses
# it into the effort vector before anything else sees it, so the recorded
# configuration is always the eight numbers.
#
# **The unit** of all eight is a multiple of `nnz << 10`, vanilla HiGHS's own
# hardcoded single-thread FeasibilityJump limit (#116), so `effort = 1.0` is
# exactly one vanilla FJ budget and a patience is directly comparable with the
# effort beside it.  The two domains below are the exact translations of the
# ones this file carried while the two parameters were denominated differently
# — efforts times 80, patiences divided by 1024 — so the space searched here is
# unchanged by the renaming and the re-basing.
###############################################################################

# --- inclusion: the zero-pattern of the four efforts -------------------------
fj                  "--fj-enabled "         c     (0, 1)
fpr                 "--fpr-enabled "        c     (0, 1)
local_mip           "--local-mip-enabled "  c     (0, 1)
scylla              "--scylla-enabled "     c     (0, 1)

# --- effort: the ceiling, budget = (nnz << 10) * value -----------------------
#
# Log-sampled, because the region of interest spans three decades: the shipped
# defaults are 2.84 / 7.672 / 29.232 / 1.136 and #106's evidence is that the
# low end — where the budget runs out before the patience gate can fire — is
# where the behaviour actually changes.
#
# The lower bound is 0.08 rather than something smaller because of FJ's hard
# granularity floor: charged effort moves in steps of CALLBACK_EFFORT =
# 500000, so `mip_heuristic_fj_effort` is a complete no-op whenever
# `nnz * value < 488`.  At 0.08 that binds below nnz ~= 6100; below it the
# parameter would be measuring nothing on a large part of any instance set.
fj_effort           "--fj-effort "          r,log (0.08, 80.0)  | fj == "1"
fpr_effort          "--fpr-effort "         r,log (0.08, 80.0)  | fpr == "1"
local_mip_effort    "--local-mip-effort "   r,log (0.08, 80.0)  | local_mip == "1"
scylla_effort       "--scylla-effort "      r,log (0.08, 80.0)  | scylla == "1"

# --- patience: the floor, in the same unit as the effort above ---------------
#
# The parameter #106 concluded actually does the limiting: the improvement-free
# effort a heuristic tolerates before giving up, so a dispatch that never
# improves spends exactly this much.  Shipped defaults are 0.71 / 1.918 /
# 7.308 / 0.284, each #113's measured p95 wait for the next incumbent
# improvement clamped to a quarter of that heuristic's ceiling — which is what
# all four of them came out as.  The four are in different units (FJ step
# units, LocalMIP coefficient accesses, Scylla `iters x nnz` per PDLP solve,
# FPR DFS work) and are not comparable to each other; equal numbers are
# meaningless.
#
# The upper bound is 128, comfortably above `80 / 4`, so that "patience at its
# ceiling" is reachable at every effort: `patience_threshold` clamps to a
# quarter of the budget (#116), so any `patience >= effort / 4` yields the same
# gate — the loosest one that can still fire.  Note that is no longer the same
# as no gate at all, which is exactly why the clamp exists; the option accepts
# 0 for that outright, which is what #113's probe sets, and it is deliberately
# not sampled here because a search wants a gate.
#
# Conditional on inclusion: a patience for a heuristic that does not run is a
# free parameter with no effect, and irace's model should not have to learn
# that.
fj_patience         "--fj-patience "        r,log (0.0009765625, 128)  | fj == "1"
fpr_patience        "--fpr-patience "       r,log (0.0009765625, 128)  | fpr == "1"
local_mip_patience  "--local-mip-patience " r,log (0.0009765625, 128)  | local_mip == "1"
scylla_patience     "--scylla-patience "    r,log (0.0009765625, 128)  | scylla == "1"
